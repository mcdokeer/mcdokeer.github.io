QuickFileTr Privacy Policy

Effective date: May 5, 2026

Overview

QuickFileTr is a cross-device file transfer and shared clipboard tool. Its single purpose is to let you pair two devices and transfer selected files or temporary clipboard text between them through a WebRTC peer-to-peer connection.

QuickFileTr does not sell personal information, does not use advertising trackers, and does not run analytics code.

Data QuickFileTr Handles

QuickFileTr may handle the following data only as needed for its file transfer and shared clipboard features:

  • Files selected by the user for transfer.
  • Clipboard text that the user explicitly pastes into the shared clipboard.
  • Temporary WebRTC connection data, such as offer and answer data, used to pair devices.
  • Temporary pairing room identifiers and timestamps used by the signaling service.
  • Optional browser-visible network information, limited to IP address and port, when the user enables network info sharing.
  • Local settings and transfer records stored in the browser, such as language, reconnect settings, device name, and recent transfer history.

File And Clipboard Transfer

File contents and shared clipboard text are transferred between paired devices through WebRTC DataChannel after the connection is established. They are not intentionally sent to the QuickFileTr signaling service.

The signaling service is used only to exchange temporary connection information required for pairing and reconnecting devices.

Remote Service

QuickFileTr connects to https://qftr.shuimuext.workers.dev/ for signaling. The service creates temporary pairing rooms and exchanges WebRTC offer/answer data. It is not used as a file storage service and does not serve executable extension code.

As with any web request, the hosting provider may process standard request metadata such as IP address, time, and user agent for delivery, security, or operational purposes.

Extension Permissions

  • clipboardRead: Used only when the user clicks the paste button in the shared clipboard panel.
  • clipboardWrite: Used only when the user clicks the copy button for received shared clipboard text or the pairing code.
  • downloads: Used so the receiving device can save files transferred through the WebRTC connection.
  • Host permission: Used to access the signaling service at https://qftr.shuimuext.workers.dev/.

Local Storage

QuickFileTr stores some data locally in the browser to support normal operation, such as language preference, device display name, reconnect information, and transfer records. This data stays in the browser unless the user clears browser storage or disables saved connection settings.

Data Retention

Temporary pairing and reconnect rooms are designed to be short-lived and are deleted after use, reset, timeout, or page close when possible. QuickFileTr does not provide user accounts and does not maintain a permanent cloud file history.

Children's Privacy

QuickFileTr is not directed to children and does not knowingly collect information from children.

Changes To This Policy

This policy may be updated when QuickFileTr changes how it handles data or permissions. The effective date at the top of this page indicates the latest version.
